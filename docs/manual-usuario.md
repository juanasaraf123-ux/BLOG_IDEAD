# Manual de usuario — Portal público del IDEAD

## Navegación

El menú superior (en celulares, el botón ☰) da acceso a:

| Sección | Qué encuentra |
|---|---|
| **Inicio** | Carrusel de novedades, cifras destacadas, accesos rápidos, noticias, próximas actividades, equipo IDEAD, mapa de cobertura y acceso a los 13 módulos de indicadores |
| **CAT** | Mapa de Colombia con los Centros de Atención Tutorial; filtro por departamento y buscador; ficha de cada CAT (historia, contacto, horarios, oferta, infraestructura, línea de tiempo, cifras integradas, proyectos, noticias y fotografías) |
| **Programas** | Oferta académica por nivel y CAT; ficha de cada programa con los CAT donde se ofrece y si recibe estudiantes nuevos |
| **Actividades** | Calendario de actividades próximas y realizadas |
| **Proyectos** | Proyectos de inversión: estado, línea, inversión, ejecución, avance y beneficiarios; ficha de cada proyecto |
| **Noticias** | Publicaciones por categoría |
| **Multimedia** | Fotografías autorizadas y videos |
| **Estadísticas** | Los 13 módulos de indicadores |
| **Transparencia** | Catálogo de los 76 indicadores con fuente, responsable, metodología y fecha de publicación; documentos y convenios públicos |
| **Sobre IDEAD** | Información institucional y equipo |
| **Buscar** | Busca programas, CAT, noticias, actividades, proyectos, indicadores y documentos públicos |

## Consultar indicadores

1. Entre a **Estadísticas** y elija un módulo (por ejemplo, *Estudiantes y matrícula*).
2. Use la barra **Filtros** (año, período, nivel, programa, departamento, CAT). Los filtros se aplican a todos los indicadores de la página y quedan en la dirección web, de modo que puede compartir el enlace con la consulta.
3. Cada indicador muestra:
   - la cifra principal con su unidad y período;
   - un gráfico adecuado a su naturaleza (barras, líneas, distribución porcentual, mapa, avance) o una tabla;
   - botones **Gráfico / Tabla**, y descargas **CSV** y **Excel**;
   - **Ficha técnica y fuente**: descripción, unidad, periodicidad, fecha de actualización, fuente institucional, dependencia responsable, metodología y observaciones.
4. **Imprimir / PDF** (menú lateral del módulo) genera una versión imprimible.

### Cómo leer los avisos

| Aviso | Significado |
|---|---|
| *Información pendiente de actualización* | La fuente aún no ha entregado datos validados; el portal no inventa cifras |
| *Metodología por validar* | La fórmula institucional del indicador está pendiente; se muestran las cifras tal como las reporta la fuente |
| *Reservado* | Cifra de un grupo muy pequeño que se oculta para proteger la identidad de las personas |
| *Publicación pendiente de autorización* | Indicador con información sensible que solo se publicará con autorización expresa |
| **DEMO** | Dato de demostración (solo en entornos de prueba): no es información oficial |

## Accesibilidad

El portal funciona con teclado (Tab, Enter, Escape), lectores de pantalla y en celulares. Cada gráfico tiene una tabla equivalente. Para reportar una barrera, use la información de contacto del pie de página.
